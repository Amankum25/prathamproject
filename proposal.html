1. Problem Statement & Scope

College departments regularly receive bills and invoices for hardware, stationery, library accessions, utilities, and annual maintenance contracts (AMC). Manual paper handling leads to untracked desk delays, missing vouchers, and vendor payment disputes. This module digitizes the entire lifecycle of submitted invoices, enforcing statutory 15-character GSTIN validation, automatic bill numbering, date boundary controls, currency amount transcription, and real-time desk-to-desk progress tracking.

3. Life-Cycle Workflow State Machine

[ Submit Bill ] → ( RECEIVED ) → [ Verify ] → ( VERIFIED ) → [ Process ] → ( PROCESSING ) → [ Pay ] → ( PAID )
Alternative: [ Return with Remarks ] → ( RETURNED ) → [ Resubmit ] → ( RECEIVED )

4. Syllabus Units Integration Plan

  • Unit 1 (PHP Basics): Associative arrays for status badges and department configurations; dynamic HTML table rendering via loops.
  • Unit 2 (String Tasks): 15-char GSTIN statutory regex validation (validate_gstin); formatted sequential bill number generation (BILL/2026-27/XXXX); verbal currency transcription in Indian numbering system (amount_in_words).
  • Unit 3 (Forms & Validation): GET multi-criteria search form; POST submission form with server-side numeric and date constraints, sticky form retention, CSRF protection, and PRG redirection.
  • Unit 4 (MySQL & CRUD): 100% prepared statements (prepare() / bind_param()); SQL JOIN with shared users; 10 realistic seed records.
  • Unit 5 (jQuery & AJAX): Decoupled backend endpoint api/search.php returning JSON; client-side jQuery script dynamically rendering the visual status timeline without page reload.
