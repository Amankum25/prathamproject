1. Executive Summary & Problem Description

The Samarth: Bill Tracking System (Module P27) digitizes the administrative handling of incoming vendor invoices and departmental expenditure vouchers across Ramanujan College. Built as an integral component of the RC Campus Connect college ERP, this module enforces statutory compliance checks—specifically automated 15-character Indian GSTIN verification, invoice date boundary controls, currency amount-in-words verbal transcription, and a desk-to-desk life cycle workflow tracking bills from submission through verification, budget sanction, and bank disbursement.

3. Desk-to-Desk Life-Cycle Workflow

[ Department Submits Bill ] → ( RECEIVED ) [ Verification Desk ]
↓
[ Verify: GSTIN & Stock OK ] → ( VERIFIED ) [ Internal Audit & Finance ]
↓
[ Sanction & Pass Order ] → ( PROCESSING ) [ Bursar & Cashier Desk ]
↓
[ Disburse: NEFT/Cheque Ref ] → ( PAID ) [ Disbursed Ledger ]

Alternative Branch: At any stage, Accounts may return the bill with mandatory remarks → ( RETURNED )

6. Security Checklist Compliance

  • SQL Injection: All queries use MySQLi parameter binding; no raw SQL string concatenation.
  • Cross-Site Scripting (XSS): All dynamic values are sanitized using e() (htmlspecialchars with ENT_QUOTES).
  • Cross-Site Request Forgery (CSRF): Hidden CSRF token on all POST requests verified via csrf_verify().
  • Access Control: Granular permissions enforced via has_role() and require_role().
